## About the Course
This capstone project applies generative AI techniques to build a QA bot leveraging RAG, LangChain, and a Gradio interface.

## What I Learned
* Building a QA Bot
* Vector Stores and Embeddings
* Gradio UI Integration
* End-to-end LLM Applications
